# Dokumen Proyek

Semua file panduan proyek tersimpan rapi di satu tempat dan siap dibagikan ke AI mana pun.

## Sub-fitur: Pustaka Dokumen

Lihat semua dokumen proyek dalam satu daftar yang mudah dicari.

## Sub-fitur: Pratinjau Isi

Baca isi dokumen langsung di layar tanpa perlu membuka aplikasi lain.

## Sub-fitur: Unduh & Salin Prompt

Ambil file .md atau salin prompt siap tempel untuk diberikan ke AI pilihanmu.

## Sub-fitur: Riwayat Versi

Kembali ke versi dokumen sebelumnya kalau ada perubahan yang tidak diinginkan.
